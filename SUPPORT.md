# Support

Thanks for using m8flow. Here's how to get help.

## Documentation

Start with the [README](README.md) and the [documentation](docs/README.md).
If something doesn't work, check
[Troubleshoot m8flow](docs/how-to/troubleshoot.md) first.

## Questions and discussion

Ask usage questions in
[GitHub Issues](https://github.com/AOT-Technologies/m8flow/issues). Search
existing issues first, because your question may already have an answer.

## Bugs and feature requests

Open a [GitHub issue](https://github.com/AOT-Technologies/m8flow/issues/new/choose)
with the bug report or feature request template.

## Security issues

**Don't** open a public issue. Follow the [security policy](SECURITY.md):
report through a GitHub private advisory or email
opensource@aot-technologies.com.

## Commercial support

For commercial support, contact **opensource@aot-technologies.com**.

## Supported versions

See the support table in [SECURITY.md](SECURITY.md) and the
[versioning policy](docs/reference/versioning.md).
